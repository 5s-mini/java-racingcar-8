# java-racingcar-precourse

---

## 1. 기본 조건

### 입력 조건

- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

###  자동차 이름 입력

- [ ] 경주할 자동차의 이름을 입력한다.

### 시도 횟수 입력

- [ ] 몇 번의 이동을 할 것인지를 입력한다.

## 2. 프로그램 동작 조건

- [ ] 자동차의 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- [ ] 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.

## 3. 출력 조건

### 경주 결과

- [ ] 차수별 실행 결과를 출력한다.
- [ ] 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- [ ] 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다.
    - [ ] 우승자는 한 명 이상일 수 있고 여러 명일 경우 쉼표(,)를 이용하여 구분한다.

## 4. 테스트 코드 작성

### 입력 테스트

- [ ] 자동차 이름 입력 테스트
    - [ ] 공백 예외 처리
    - [ ] null 예외 처리
    - [ ] 이름이 5글자보다 길 경우 예외 처리
    - [ ] 쉼표로 구분되지 않을 경우 예외 처리

- [ ] 시도 횟수 입력 테스트
    - [ ] 공백 예외 처리
    - [ ] null 예외 처리
    - [ ] 양의 정수가 아닐 경우 예외 처리

### 출력 테스트

- [ ] 자동차 경주 결과 출력 테스트
    - [ ] 매 차수별 실행 결과 출력
    - [ ] 최종 우승자 출력
